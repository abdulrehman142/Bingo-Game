# Bingo-Game
A Bingo game using the PDCurses library is a terminal-based application that brings the classic Bingo experience to life. The game generates a random 5x5 Bingo card for the player, with numbers filled according to Bingo rules (e.g., columns labeled B, I, N, G, O and containing respective ranges). It utilizes PDCurses to display the card, update called numbers, and manage interactions.

Features:
1-Interactive Display
2-Keyboard Control
3-Game Management
4-Dynamic Updates
